# DRF Snippets API

A Django REST Framework tutorial project with Docker and Docker Compose.

## Tech Stack

- Python
- Django
- Django REST Framework
- Docker
- Docker Compose

## Features

- RESTful API
- Serializers
- Generic Views
- ViewSets & Routers
- Authentication & Permissions
- User-owned snippets
- Browsable API
